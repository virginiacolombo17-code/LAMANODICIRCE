# La Mano di Circe

Editoriale indipendente in italiano, tra scienza, filosofia, storia delle idee e tradizioni simboliche.

## Avvio locale

```bash
npm install
npm run dev
```

Verifica produzione: `npm run build`.

## Struttura

- `src/data.ts`: contenuti dimostrativi e categorie editoriali.
- `src/types.ts`: modelli TypeScript per articoli e categorie.
- `src/App.tsx`: layout condiviso, navigazione e pagine React Router.
- `src/styles.css`: design system responsivo e direzione artistica.

I contenuti sono mock locali. Il modulo di collaborazione e la newsletter mostrano feedback di demo ma non inviano né archiviano dati. Non è configurato un backend o un CMS. La struttura dei contenuti è pronta per un’integrazione futura con Sanity; l’illustrazione della mano attualmente è un segnaposto grafico, da sostituire con l’asset originale quando disponibile.

Le note editoriali segnalano le citazioni scientifiche che richiedono verifica: non sono state inventate fonti di ricerca.
